# React User Management

A simple React application that fetches and displays user details from the JSONPlaceholder API. The application displays user information in an organized and user-friendly interface.

## Features

- Fetch user details from REST API
- Display user information
- Show Name, Email, Phone, City, and Company
- React-based component structure
- Dynamic data rendering using API response
- Clean and responsive UI

## Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- REST API
- JSONPlaceholder API

## API Used

[JSONPlaceholder Users API](https://jsonplaceholder.typicode.com/users)

## User Details Displayed

The application displays the following user information:

- **Name** – User's full name
- **Email** – User's email address
- **Phone** – User's contact number
- **City** – User's city
- **Company** – User's company name

## Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/cirilarockiaraj/fetch-and-display-api-data-using-react
```

### 2. Navigate to the Project Directory

```bash
cd fetch-and-display-api-data-using-react
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

## Project Purpose

This project demonstrates how to fetch data from a REST API and display it dynamically using React components.

It helps practice API integration, asynchronous JavaScript, React state management, and rendering dynamic data.
